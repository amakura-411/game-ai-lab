# game-ai-lab

ゲームAIおよびC++の学習・実験用リポジトリです。

知識を読むだけではなく、小さな課題を実際に実装し、

**要件整理 → 仕様策定 → 設計 → 実装 → 振り返り**

まで一通り経験することを目的としています。

## Goals

- C++の基礎を実装を通して身につける
- ゲームAIの基本的な考え方を理解する
- 要件から自分で仕様・設計を考える練習をする
- 実装した内容について、技術的な判断理由を説明できるようにする
- 小さな成果物を継続的に完成させる

## Learning Policy

各課題では、最初から実装方法を決めず、与えられた要件から自分で仕様を策定します。

完成度を上げ続けることよりも、

1. 動くものを完成させる
2. 問題点を見つける
3. なぜその設計にしたのか振り返る
4. 新しく学んだ知識を次の課題で試す

というサイクルを重視します。
