## 今日のお題

「空腹によって行動が変わるNPC」

## 要件

- NPCには「名前」「HP」「空腹度」がある
- 1ターンごとに空腹度が増える
- 空腹度によって行動が変わる
  - 食事
  - 待機
- 行動結果と現在状態をコンソールに表示する
- 10ターン程度動かせる
- クラス・継承・ポインタ等、まだ習っていない機能は禁止

## 追加要件

- 各パラメータについて
  - 名前: スタート時に標準入力で設定する。
  - HP: 5固定
  - 空腹度: 初期値は0
  - ターン数：最初が1でMAXが10
- 空腹度は1 ~ 10 でランダムに増え
- 空腹度が5以上の時、食事を行う
- 食事を行うと、1 ~ 3 でランダムに空腹度を減らすことができる。ただし、空腹度は0までしか下がらない
- 空腹度が10以上になった時に実行。
  - 空腹度を0にし、HPをランダムで1 ~ 3 減らす
- HPが0になった場合、GAME OVERとなる
- HPが0になることなく、10ターンを超えたらクリア
- HPを増やす方法はない

```
{ターン数}目

{名前}のHP: {hitpoint}
空腹度が{増加数}上がった！（現在の空腹度：{空腹度}）

{名前}の行動： {action}

{action が食事の時のみ}
{名前} はリンゴを食べた。空腹度が{recover}回復！（現在の空腹度：{空腹度}）

{空腹度 >= 10の時}
  {hitpointを-1する}
  名前の空腹は限界だ！ {名前}のHP: {hitpoint}
  {空腹度を0にもどす}

{hitpointが0になった}
  {名前}は死んだ
  GAME OVER
  {ループをbreakする}


{ターン数 === 10の時} GAME CLEAE
```
